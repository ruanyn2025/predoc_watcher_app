# Predoc Watcher

盯着三个 pre-doc / RA 招聘页，把岗位变成一个能翻、能搜、能收藏、能提醒的小软件。

自带抓取、自带数据库，装完就能用 —— 不需要 API key、不需要邮箱、不需要任何账号。

| 来源 | 页面 |
|---|---|
| predoc.org | <https://www.predoc.org/opportunities> |
| NBER（本部） | <https://www.nber.org/career-resources/research-assistant-positions-nber> |
| NBER（非本部） | <https://www.nber.org/career-resources/research-assistant-positions-not-nber> |

## 安装

需要 **Python 3.9+**（[下载](https://www.python.org/downloads/)，Windows 安装时记得勾
"Add Python to PATH"）。

```bash
git clone https://github.com/ruanyn2025/predoc_watcher_app.git
cd predoc_watcher_app
pip install -r requirements.txt
```

然后双击 `启动.bat`，或者 `python desktop.py`。第一次启动会去抓一遍三个网站、
建立本地数据库，要几秒钟。

> Windows 以外：窗口和托盘依赖 pywebview / pystray，主要在 Windows 上验过。
> Mac / Linux 可以跑纯网页版（见下方「只要网页版」），那部分是跨平台的。

## 启动

双击 `启动.bat` —— 开出一个独立窗口，没有地址栏，任务栏里是自己的图标。

**关窗口不等于退出**：点 ✕ 只是缩到系统托盘，程序继续在后台检查新岗位。
要真正退出，**右键托盘图标 → 退出**。左键托盘图标把窗口叫回来；
重复双击 `启动.bat` 也只会叫回已有窗口，不会开出第二个实例。

### 装进「开始」菜单

想在开始菜单的应用列表里找到它（而不是每次去翻文件夹）：

```powershell
.\install_shortcut.ps1
```

```powershell
.\install_shortcut.ps1 -Desktop     # 顺带一个桌面快捷方式
.\install_shortcut.ps1 -Startup     # 顺带开机自启（缩到托盘启动，不弹窗）
.\install_shortcut.ps1 -Uninstall   # 全部移除
```

快捷方式直接指向解释器而不是 `启动.bat` —— 走 `.bat` 会闪一下黑框。

### 指定 Python 解释器

不配置也能跑：默认用 PATH 里的 `pythonw`。只有当你的 Python 不在 PATH 上
（比如装在 conda 环境或虚拟环境里）才需要指定。三种改法，按优先级：

| 方式 | 怎么做 | 适合 |
|---|---|---|
| 环境变量 | 设 `PREDOC_PYTHON` 为解释器完整路径 | 想全局生效、不改仓库里的文件 |
| **`python_path.txt`** | 在 `webapp/` 下建这个文件，里面写一行完整路径 | **虚拟环境 / conda 环境，推荐** |
| PATH | 什么都不做 | 系统装的 Python |

`python_path.txt` 已在 `.gitignore` 里，各人的路径不会互相覆盖。
`install_shortcut.ps1` 用的是同一套查找顺序。

**用虚拟环境的话**：

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

然后把解释器路径写进 `python_path.txt`（用 `pythonw.exe` 不弹黑框）：

```
C:\完整路径\.venv\Scripts\pythonw.exe
```

注意**不能靠「先激活 venv 再双击」** —— 双击启动器会开一个新进程，
继承不到你在终端里激活的环境。所以必须把路径写下来。

命令行等价写法：

```
python desktop.py
```

| 参数 | 作用 |
|---|---|
| `--minimized` | 启动后直接缩到托盘，不弹窗 |
| `--interval 6` | 后台自动检查的间隔（小时），默认 6 |
| `--no-fetch` | 启动时不抓取 |
| `--port 8000` | 换端口 |

### 后台行为

- 启动时抓一次；
- 点 ✕ 缩到托盘时**顺手再抓一次**；
- 之后每隔几小时自动抓（`--interval`）；
- 抓到新岗位会弹一条托盘通知，点开窗口就能看到。

### 只要网页版

不想要窗口和托盘，直接跑 `app.py` 就是纯网页版，用浏览器打开
<http://127.0.0.1:8765/>，也不需要装 pywebview / pystray：

```
python app.py
```

## 外观

右上角有两个按钮：**半明半暗的圆**切主题，**地球**切语言。

主题三态：**跟随系统 / 浅色 / 深色**。选了浅色或深色就锁定，两个方向都能压过系统偏好。
`data-theme` 由服务端直接渲染在 `<html>` 上，所以打开页面不会闪一下另一种配色。

底面是中性的白与黑，橙只留给需要被看见的小元素 —— 数字气泡、星标、主按钮、当前页
下划线。大面积铺橙会把这些强调点淹掉，反而看不出重点在哪。

## 多语言

点右上角的**地球图标**弹出选单，五门语言任选：

简体中文 · 繁體中文 · English · Français · Español

选择存在数据库里，下次打开还是上次那门。选单里每门语言用它自己的文字显示 ——
翻译成当前语言反而认不出来。

所有界面文案集中在 `i18n.py` 的 `S` 字典，每条是一个五元组，顺序对应 `LANGS`。
加一门语言就是给每条补一列，文件末尾有一道自检，数错列会在导入时直接报错，
不会悄悄漏翻。

几处中文不存在、西文才有的问题：

- **单复数**：西文串用 `|` 分隔（`{n} result|{n} results`），按数字自动选。
  直译会出现 "1 reminders this month"。
- **括号**：中文用全角 `（剩余 8 天）`，西文用半角且带前导空格 ` (8 days left)`，
  所以括号本身也在翻译表里，没写死在模板中。
- **日期语序**：英文 `Sep 06`，法语西语是「日 月」的 `6 sept.`，中文 `09月06日`。
- **月份大小写**：法语和西语的月份不首字母大写（`septembre 2026`），这是正字法。

## 五个页面

**首页** —— 自上次「标为已读」以来的新增岗位，按抓取日期分组；顶部是未来 7 天内
到期的收藏提醒，剩 3 天以内会标红。

**历史列表** —— 全部岗位（含已下架）。搜索框跨**领域 / 导师 / 学校学院 / 标题**匹配，
空格分隔的多个词按「同时满足」处理，例如 `labor harvard` 会同时命中领域和机构。
还能按来源、在招状态筛选。

**收藏夹** —— 按提醒日期排序，已处理的折到下面。

收藏之后随时能改：每张卡片右上角有个 **✎ 编辑** 按钮，点开就能改提醒日期和备注，
原值都带着出来。改完保存，收藏夹和日历会按新日期重排。

★ 是常规行为：点亮的星取消收藏。面板里也有一个 Remove 按钮，效果一样。

**申请追踪** —— 在收藏夹点「完成投递」，岗位就从收藏夹搬到这里。每条可以：

- 按**申请阶段**分组（已投递 / 笔试 · code test / 面试 / 结束），一个下拉框切换，「结束」的自动折到底部；
- 记**多个带名字的时间点**（「code test 截止 9/18」「一面 9/25 10:00」）—— 收藏夹一条只能有一个提醒日期，装不下这些，所以另建了一张标注表；
- 写**备注**气泡（可以有好几条）和**相关链接**（自定义名称，点了用系统浏览器打开）；
- 顶部显示投递日期和「已 N 天」，方便判断哪些该跟进了。

**这三栏在收藏页也有** —— 还没投的岗位一样能记时间、写备注、贴链接。

标注的时间点会**直接汇入日历页**。日历上两类标记各用一种色相 —— 收藏提醒是黄色、
申请事件是蓝色，都避开界面主色的橙，否则在浅橙底子上根本分不出来；**7 天内的用实心、
更远的用浅底**，紧迫程度一眼可辨。光标停在标记上会浮出岗位细节（机构、导师），
点击则跳回它所属的收藏夹或申请追踪页并定位到那张卡片 —— 在日历上你想做的是去处理它，
而不是再读一遍招聘启事。撤回投递会退回收藏夹，**但标注不删** —— 误点一下不该毁掉写过的东西。

备注从「一个岗位一条」改成了气泡，所以收藏面板里原来那个备注输入框去掉了，
两套并存会让人不知道该写哪个。老库里已有的备注会在首次启动时自动搬成气泡。

**日历** —— 月历视图，标出所有收藏岗位的提醒日，可翻月。

## 提醒日期是怎么定的

这是本软件唯一需要你参与判断的地方，原因是数据源的截止日期字段很脏。
对 208 条实测：

| 情况 | 条数 | 占比 |
|---|---|---|
| 完全没有 deadline 字段（全部 NBER 岗位） | 119 | 57% |
| 纯 rolling，无固定截止 | 50 | 24% |
| 只含日期 | 21 | 10% |
| rolling + 含日期 | 17 | 8% |
| 有文字但认不出日期 | 1 | 0% |

能抽出日期的 38 条里，11 条没写年份、19 条已过期 —— 也就是只有个位数的岗位
有干净可用的截止日期。格式还五花八门：`20th April 2026`、`5/24/26`、
`First review on 9/15/26, then rolling`、`Rolling with priority deadline of August 2, 2026`。

所以点 ☆ 收藏时会弹出一个面板：

- **原始截止信息**原样显示，让你自己核对；
- **程序判断**说明它是怎么读的（比如「原文没写年份，按最近的未来推断为 2027 年」）；
- **提醒日期**已经预填好 —— 抽到未来的日期就用那个日期，抽不到（rolling / 无字段 /
  日期已过期）就预填 7 天后；
- 一排快捷按钮（提前 3 天、就在截止日、14 天后……），或者直接改日期框。

回车确认，Esc 取消。

## 数据从哪来

`fetch.py` 现场访问三个网站并解析，`ingest.py` 把结果写进 `jobs.db`（SQLite）。
启动时自动抓一次，之后随时点右上角「刷新」重抓。

**第一次运行 = 建立快照**：抓到的岗位全部记为存量，进历史列表但**不算新增** ——
否则新用户一打开就会被两百多条"新增"糊一脸。从第二次运行起才走新增逻辑。

**为什么要自己建库而不是每次现抓现看**：

- 网站只提供"当前在招"，**没有发布日期字段**。所以「抓取于 ○○」那个徽章是本软件
  首次见到该岗位的日期，一旦定下就不再改动；
- 网站上岗位一撤就没了，本软件**保留下来标记为「已下架」**，历史才完整；
- 因此**历史从建库那天开始积累**，更早的没法回填。

### 抓取护栏

站点改版或网络故障时，最坏的结果是解析出 0 条被当成"岗位全下架了"，等站方恢复
又全部变成"新增"轰炸一遍。所以：每个来源必须找到自己的锚点结构（`article.sorted`，
或 `Available Positions` 标题）并达到最少条数，任一不满足就判为**抓取失败**；
失败来源的岗位**原样保留、绝不标下架**，且各来源独立失败，一个挂了不影响另外两个。


## 排错

**打不开网页** —— 端口 8765 可能被占了，换一个：`app.py --port 8000`。

**提示某个来源抓取失败** —— 偶发通常是网络抖动，该来源的岗位会原样保留、不会丢。
反复出现说明站方改版了，`fetch.py` 里的解析器需要更新。

**报 CERTIFICATE_VERIFY_FAILED** —— predoc.org 只发了叶子证书、漏发 GoDaddy 中间证书。
浏览器能打开是因为 Windows 会自动补下载，Python 不会。`extra_ca/gdig2.pem` 就是那张
补上的证书，运行时与 certifi 合并 —— 证书校验始终开着，没有关掉。

**想清空重来** —— 删掉 `jobs.db` 再启动即可重新建库，但**收藏和提醒会一起丢**。

## 图标

像素风的 `pre` / `doc` 两行字，黑底 + 白橙。

之所以是像素画而不是矢量：**托盘图标实际只有 16~24px**，普通字体缩到那个尺寸会糊成
一团。所以直接在 16×16 网格上按 3×5 的字模逐像素画，再整数倍放大 —— 每个尺寸都锐利。
6 个字母横排在 16px 里放不下（每个字母只剩 2px），拆成两行才装得下。

改设计就编辑 `make_icon.py` 里的 `GLYPH` 字模和颜色，然后重跑：

```
python make_icon.py
```
